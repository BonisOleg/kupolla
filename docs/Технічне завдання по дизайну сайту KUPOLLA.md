Технічне завдання по дизайну сайту KUPOLLA

**Кольорова концепція**  
Основний фон усіх сторінок \- білий.  
Максимум вільного простору “повітря”.  
   
Якщо десь потрібно зробити фон, робимо чорний або графітовий (\#202020) 

Для важливих секцій/блоків  фонів не робимо можемо виділити тільки рамками з тінню 

**Градієнт**

Усі акцентні елементи виконуються у фірмовому градієнті KUPOLLA (\#00311e \+ \#051f43 )  
.  
Градієнт використовуємо для:

* кнопок;  
* активних елементів;  
* іконок (де доречно);  
* декоративних елементів;  
* верхнього меню після скролу;  
* окремих графічних блоків;  
* акцентних ліній та деталей.

**Важливо: градієнт використовується саме як акцент, а не як основний фон сторінки.**

**Навігація (Header)**

Початковий стан

Поки користувач знаходиться на першому екрані:

Header прозорий.  
Меню розташоване поверх фотографії.  
Лише текст навігації без кольорового фону.

Після початку скролу:  
Фон Header змінюється на фірмовий градієнт.

**Стиль інтерфейсу**  
Основні принципи:  
багато білого простору;  
мінімалізм;  
**великі фотографії;**  
сучасна типографіка;  
мінімум декоративних деталей;

Текст
